# Auto-X 前端功能点清单

这份清单是重构后的页面基准。页面统一使用 Ant Design Vue，业务接口继续复用 `src/services/api.ts`。

## 认证与工作台

- 登录：用户名、密码校验，登录后跳转原目标地址。
- 会话：读取当前用户、退出登录、路由鉴权。
- 安全：修改登录密码，并在修改成功后重新登录。
- 仪表盘：监听账号、内容、轮询和成功率指标；60 秒自动刷新；展示轮询趋势、服务健康、最新采集内容和最近任务。

## 监听与采集

- 监听账号：搜索、按运行状态筛选、分页；新增、编辑、暂停、恢复、立即轮询、删除。
- 内容流：关键词、账号、日期筛选和分页；查看 X 原文；多选后批量 QQ 推送；基于单条内容创建 AI 创作任务。
- 轮询记录：按账号、状态、触发来源和时间范围筛选，分页查看执行结果、耗时、采集数量和错误信息。

## 运行与数据源

- 运行监控：10 秒刷新 CPU、内存、磁盘、进程、服务和 Worker 状态，展示资源百分比、延迟、心跳和错误。
- 日志监控：选择 Backend / Worker / AI Worker / QQ Worker / 小红书 Worker，建立 SSE 实时日志流；暂停、恢复、重连、清空、自动滚动。
- X 数据源：在官方 API 与 twscrape 间切换；保存、测试、轮换、删除 Bearer Token 或 Cookies；展示加密存储和校验状态。

## AI 创作与文章

- AI 数据源：配置名称、Base URL、模型和 API Key；读取模型、测试连接、删除数据源。
- AI 设置：启用创作、采集后自动生成、语言、语气、推理强度、重试次数、输出 Token、请求超时和默认 Skills。
- Skills：新增、编辑、启用/停用、删除 Skill。
- AI 任务：按状态筛选、分页、重试失败任务、删除任务、编辑生成草稿。
- 用户上下文：按监听账号和功能点读取/保存 Skill 绑定，查看作者画像和长期主题。
- 文章管理：搜索、按状态/来源筛选、分页；新增、编辑、删除、上传媒体、发布到 X / QQ / 小红书、查看发布历史。

## QQ 渠道

- QQ 推送总览：机器人、群目标、队列和失败投递统计。
- QQ 机器人：新增、编辑、启用/停用、测试连接、删除。
- 群目标：绑定机器人与群 OpenID，选择监听范围，编辑模板，启用/停用、测试、删除。
- 投递记录：按状态、任务筛选和分页；失败投递支持重试。
- QQ 任务：按秒/分钟/小时/天/周/月配置定时消息；关联机器人和群；启停、编辑、删除、查看/清除历史。

## 小红书与系统

- 小红书：保存 `a1` 与 `web_session` 登录态；上传或粘贴图片；编辑标题与正文；发布图文；发布过程轮询安全验证二维码。
- 系统设置：配置默认轮询间隔和最大并发，校验范围后保存或重置。
- 404：提供返回仪表盘和返回上一页入口。

## 视觉与交互基准

- 暖白背景、深墨导航、低饱和陶土色为唯一主强调色。
- 使用大留白、细边界、轻阴影和编辑式标题，避免渐变堆叠与装饰性卡片。
- 所有操作提供 loading、成功/失败反馈、危险操作二次确认和键盘焦点状态。
- 375px、768px、1024px、1440px 下保持可用，无横向滚动。
